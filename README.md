# Mana Tech AutoPilot

Photo-first, cloud-based Instagram publishing for Mana Tech Telugu.

## Daily workflow (Asia/Kolkata)
- **10:00 AM:** Prepare 3 image posts with headlines, descriptions, captions, hashtags, and source details; add the images and post metadata to this repository.
- **11:00 AM:** GitHub Actions reads the queued posts and publishes them to Instagram through the official Meta API.
- Videos remain manual uploads by the account owner. Video generation is out of scope for now.

Publishing stays disabled until Meta permissions and public media delivery are verified. Never commit access tokens or other secrets.
