# Reel Engine

Target output: one cinematic Telugu technology Reel for 18:00 Asia/Kolkata.

Initial production target:
- 9:16 vertical, 1080×1920.
- Approximately 30–45 seconds.
- Telugu narration with synchronized subtitles.
- Licensed stock footage, cinematic pacing, music, and sound effects.
- FFmpeg-based assembly on suitable rendering compute.

Quality gate:
- Verify the output file can be decoded.
- Verify dimensions, duration, frame rate, and audio stream.
- Check narration is present and subtitles are readable.
- Reject watermarks, missing scenes, corrupt clips, and unlicensed assets.
- Record every asset source and license.

Start with a single sample Reel before implementing unattended batch production.
